# K-Line Market Behavior Lab

## 📖 简介

**K线市场行为研究实验室** 是一个专注于K线形态和市场行为研究的独立VeighNa应用。

## ✨ 核心功能

### 1. 丰富的特征库
- **67个K线特征** - 涵盖9大类别
  - 收益类、K线结构、波动率、成交量
  - 趋势、动量、反转、形态、截面

### 2. 研究模板
- **8个预置模板** - 快速启动研究
  - 大阴线底部反转
  - 突破新高
  - RSI超卖
  - 回踩MA20支撑
  - 放量突破
  - 锤子线
  - 均线多头排列
  - 缩量盘整

### 3. 智能验证
- **实时条件验证** - 即时反馈
- **依赖特征提示** - 智能建议
- **语法检查** - 避免错误

### 4. 灵活采样
- **4种采样规则**
  - ALL - 全部事件
  - FIRST_TRIGGER - 首次触发
  - COOLDOWN - 冷却期（推荐）
  - NON_OVERLAP - 非重叠

## 🚀 快速开始

### 安装

应用已集成到VeighNa中，无需额外安装。

### 使用

1. **启动VeighNa Studio**
2. **在应用中心找到 "K-Line Behavior Lab"**
3. **点击打开**
4. **开始研究**

### 基本流程

1. 选择数据集
2. 选择研究模板或自定义条件
3. 配置采样规则
4. 开始研究
5. 查看结果
